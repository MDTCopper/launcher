# v0.2.0 alpha 2 热修复
这是一个检查更新的热修复版本
这一版基本只动**检查更新这条链路**：更新说明改用和模组页同一套 README 渲染器，不再是一坨纯文本；
下载能看到字节与速度；点「现在更新」之前会先确认一次；
以及**安装时整个应用不再卡住**。

> [!warning]
> 当前版本仅发布 Windows 版本。Linux / macOS 的构建与打包链路已写进脚本，但**未在对应系统实测**；Android 端的启动流程尚未开发。

## 修复

### 更新时整个应用卡住
- 真因是托盘模式拦下了窗口的关闭请求：安装器发出关闭请求后，启动器把它当成「关窗」收进托盘，安装器就一直等 → 看着像卡死
- 现在进入安装 / 覆盖流程前先放开关闭拦截，退出后还有一层兜底

### 下载没有具体进度
- 更新任务的卡片原来只有一个百分比，现在显示「已下载 / 总量 · 速度」

### 更新前没有提示
- 加了一层确认弹窗（安装版与解压版文案不同，都会说明启动器会退出）

## 变动

- **更新说明改用 README 渲染器**：release 说明里的标题、列表、表格、图片都能正常显示
- 关于页补上国内论坛 MDTBBS 的鸣谢

> [!warning]
> - **未做代码签名**：安装包与 exe 会触发 SmartScreen，提示时选「更多信息 → 仍要运行」即可
> - 数据根目录：解压版就在 exe 旁边（`config.bin` / `versions` / `logs` 都在那里）；安装版在当前用户目录下
> - 预览版，后续版本仍可能有破坏性变更
> - **要收到更新，得用 `v0.1.0 alpha 6` 之后的版本**

## 反馈

遇到问题欢迎开 Issue，**附上启动器日志**（数据根目录下的 `logs/`）会好定位很多。

> [!note] 
> 如何选择 Assets？  
> Windows：
> - `copper-launcher-v0.2.0-alpha2-windows-x64.zip` -> 直接解压，双击 exe 即可运行
> - `copper-launcher-v0.2.0-alpha2-windows-x64-setup.exe` -> 双击安装即可使用
>
> 两者可以混用：安装版以后走安装包更新；解压版会在启动器退出后自动覆盖并重新打开。
