# v0.2.0 alpha 1 发布 - 接入国内下载源

这一版把**下载这条线整个重做了一遍**：接入国内源（论坛 MDTBBS），版本列表与游戏本体都能从国内 CDN 拉；下载来源变成可选、列表跟着来源走；镜像节点按能力分家择优。另外**窗口收进托盘 / 最小化后不再逐帧渲染**，后台不再白耗 GPU。

> [!warning]
> 当前版本仅发布 Windows 版本。Linux / macOS 的构建与打包链路已写进脚本，但**未在对应系统实测**；Android 端的启动流程尚未开发。

## 新增

### 国内下载源（MDTBBS）
- **版本列表优先走国内源**：一次拿全量版本，不吃 GitHub 的匿名额度；拿不到才退 GitHub API，再退本地快照
- **游戏本体从国内 CDN 下载**：支持分块并发，并且**下载完校验 sha256**
- 来源地址在下载弹窗里可见（`下载来源　国内源 / 官方源`），日志里也会打出实际用的地址

### 本体下载来源可选
- 设置 → 下载 → 「**本体下载来源**」四档：优先国内源（默认）/ 优先官方源 / 只用国内源 / 只用官方源
- 「优先」的两档在下不动时会**自动换另一边再试**（每个来源独立做大小 + sha256 校验；取消 / 暂停不会换源）
- 选「只用」时**版本列表也跟着变**：只用国内源就只列国内源有的版本（v126 起），不会列出选了下不动的版本；BE 入口同时隐藏

### 镜像节点按能力分家
- 节点的 raw / api / github 三类地址**各自探测、各自择优**
- 下载优先挑**支持 Range（分块）**的节点；探针延迟改为量「首字节」
- 预设节点表已按新规则重新测过一遍（`remote/github_mirrors.hjson`）

## 变动

- **正式版列表按大版本分段**：v8+ / v7 / v6 / v5 / v4 / v3 及更早，段标题带版本区间
- 修正 **Classic 与远古版**的划分：v70 前是 Classic（官方 v1–v3 原始版本），v70–v96 是远古版
- **窗口不可见时停掉所有动画**：收进托盘或最小化后不再渲染
- 加载器下载卡片显示字节数与速度
- 去掉版本列表的 git ref 兜底

## 修复

- 选中版本时路径形态不一致导致**选不中**
- 配置里的路径在启动时**归一化**：数据根搬家 / 换盘后仍能找到本体与加载器
- 托盘关窗行为不再被「启动后最小化」的设置带偏
- 下载：断网不再空转重试；修掉单路下载时的误报；补上过程日志

> [!warning]
> - **未做代码签名**：安装包与 exe 会触发 SmartScreen，提示时选「更多信息 → 仍要运行」即可
> - 数据根目录：解压版就在 exe 旁边（`config.bin` / `versions` / `logs` 都在那里）；安装版在当前用户目录下
> - 预览版，后续版本仍可能有破坏性变更
> - **「检查更新 → 下载 → 覆盖 → 重启」这条链路是第一次随版本发布**

## 反馈

遇到问题欢迎开 Issue，**附上启动器日志**（数据根目录下的 `logs/`）会好定位很多。

> [!note] 
> 如何选择 Assets？  
> Windows：
> - `copper-launcher-v0.2.0-alpha1-windows-x64.zip` -> 直接解压，双击 exe 即可运行
> - `copper-launcher-v0.2.0-alpha1-windows-x64-setup.exe` -> 双击安装即可使用
>
> 两者可以混用：安装版以后走安装包更新；解压版会在启动器退出后自动覆盖并重新打开。
