# v0.2.0 alpha 3 发布 - 修耗电、镜像更稳、界面微调

这一版三件事：**关掉彩色背景后仍在后台逐帧渲染、白耗 CPU / GPU 的坑修了**；**GitHub 镜像改成 api / raw / github 三族各排一张表**（节点抽风会自动换下一个，节点请求也不再走代理）；外加下载弹窗、抽屉与卡片的几处界面微调。

> [!warning]
> 当前版本仅发布 Windows 版本。Linux / macOS 的构建与打包链路已写进脚本，但**未在对应系统实测**；Android 端的启动流程尚未开发。

## 修复

### 关掉彩色背景后仍在后台出帧（耗 CPU / GPU）
- 真因：流光背景起动画时漏判「彩色背景是否开启」——关掉之后，界面每重建一次就又把动画启动了。painter 不画（肉眼完全看不出来），但每个 vsync 都在出帧
- 实测（前台静默、彩色背景关）：**CPU 45.4% → 0.7%（单核）、GPU 3d 12.36% → 0%**
- 顺带：关掉彩色背景现在是真正的零每帧开销

### 镜像节点抽风会拖死整批请求（图标 / README 大面积拉不到）
- 原来：镜像回 403 / 429 / 5xx 时既不换节点也不降权，最优节点还会被缓存 10 分钟；图标那边还会把一次失败记成「这个模组没有图标」——一次抽风就是一整页图标拉不到，且本次运行内不再重试
- 现在：
  - **api / raw / github 三族各排一张表**（各自 10 分钟有效期，能测通的节点按延迟排好），请求顺着表往下试
  - **节点级失败**（连不上 / 403 / 429 / 5xx）自动换下一个，失败过的挪到表尾、成功过的提到表头；只有 404 / 401 这类上游真实答复才直接抛出
  - 节点全用完**回退直连**
- **镜像节点请求不再走代理**：节点本来就是「绕开代理上 GitHub」用的，被代理绕出去容易失败、变慢

### 其它
- 版本选择页顶部的「详细路径」现在显示**完整绝对路径**（之前印的是配置里那种相对记录形态，只显示成 `versions`）
- 关于页不再露出未完成的「加入我们」占位

## 变动

- **下载弹窗宽度自适应**：窄窗口下按窗口宽度收窄（原来固定 500 宽，小窗口会被撑破）
- **抽屉与卡片样式微调**：抽屉信息区、任务列表、内容面板、按钮统一了一遍；新增 `CopperCard` 卡片组件；主题色板补 `shadow`
- **镜像预设节点表重新实测**（`remote/github_mirrors.hjson`，2026-09-29）：换了几个新节点、按新速度排序，之前会大面积 4xx 的节点已剔除

> [!warning]
> - **未做代码签名**：安装包与 exe 会触发 SmartScreen，提示时选「更多信息 → 仍要运行」即可
> - 数据根目录：解压版就在 exe 旁边（`config.bin` / `versions` / `logs` 都在那里）；安装版在当前用户目录下
> - 预览版，后续版本仍可能有破坏性变更
> - **要收到更新，得用 `v0.1.0 alpha 6` 之后的版本**（更早的产物里没有「检查更新」入口）

## 反馈

遇到问题欢迎开 Issue，**附上启动器日志**（数据根目录下的 `logs/`）会好定位很多。

> [!note] 
> 如何选择 Assets？  
> Windows：
> - `copper-launcher-v0.2.0-alpha3-windows-x64.zip` -> 直接解压，双击 exe 即可运行
> - `copper-launcher-v0.2.0-alpha3-windows-x64-setup.exe` -> 双击安装即可使用
>
> 两者可以混用：安装版以后走安装包更新；解压版会在启动器退出后自动覆盖并重新打开。
