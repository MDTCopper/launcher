Mindustry 第三方启动器

把 Mindustry 装进一个趁手的启动器

多版本共存、Copper 加载器与模组管理、GitHub 镜像加速、系统托盘，桌面端与手机端同一套体验。 基于 Flutter 开发，Windows / Linux / Android 三平台。

特性

从建版本到进游戏，路上要用的东西都在启动器里。

版本管理

  • 同时管理多个游戏版本，版本之间可以隔离存档
  • 版本列表取自官方仓库，并内置快照，断网也能浏览历史版本
  • 按时代分段（正式版 / Classic / 远古版），标注各时代的能力差异
  • 支持指定 build 与预览版（BE）
  • 记录每个版本的游玩时长与最近启动时间
  • 生成 .bat / .sh 启动脚本，可脱离启动器直接启动

启动游戏

  • 启动前配置 JVM 参数，并按可用内存与已启用模组体积自动分配堆内存
  • 管理多个 Java 运行环境，缺失时从 Adoptium 自动下载
  • 按游戏版本挑兼容的 Java，老版本用 Java 8 最稳
  • 覆盖游戏内设置与多人游戏用户名
  • 启动后可收进系统托盘，游戏退出自动弹回
  • 单实例运行，重复启动会唤回已有窗口

模组管理

  • 浏览并下载官方仓库模组，jar / zip 均可
  • 启用 / 禁用模组时同时改写游戏设置与文件后缀，官方加载器不会误扫到已禁用的模组
  • 批量多选、拖动连续选择、搜索与分类筛选
  • 桌面端支持拖入文件一键导入
  • 对 Copper 加载器与它的原生模组提供专门支持

网络与下载

  • 统一网络层：自动 UA、分块多线程下载、断点续传、下载限速
  • GitHub 镜像加速：github / raw / api 三类分别实测延迟排名，失败自动换节点
  • 代理三模式：跟随系统 / 自定义 / 关闭
  • 游戏本体从国内 CDN 下载并校验 sha256

Android 手机也能跑桌面版游戏

首次启动会自动装好 Java 运行环境与 Copper 桥（约 40 MB），装完即可运行桌面版本体。 不需要自备 Java，也不需要自己折腾运行环境。
